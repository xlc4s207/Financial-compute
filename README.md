# Fund OS · 课题组经费管理

> 一个简洁明了的课题组流动资金管理网站：记录每一笔收入与支出，实时显示当前结余、每笔交易后的余额与支出构成。

**🚀 在线使用：[https://jacketlong23.github.io/Fund-OS/](https://jacketlong23.github.io/Fund-OS/)**

手机、电脑浏览器均可访问，无需安装、无需注册。

---

## 功能

| 模块 | 能做什么 |
| --- | --- |
| **余额总览** | 大字显示当前结余，累计收入 / 累计支出 / 本月支出一目了然 |
| **记一笔** | 支出 / 收入两种类型，填写金额、项目用途、类别、日期、经手人、备注 |
| **流水明细** | 每一次记录完整保留，按月分组，每笔显示**交易后结余** |
| **筛选搜索** | 按支出 / 收入筛选，按项目、备注、经手人关键字搜索 |
| **支出构成** | 按类别汇总支出，条形图直观呈现钱花在哪里 |
| **编辑 / 删除** | 点击任意记录即可修改；悬停可删除（带二次确认） |
| **数据备份** | 一键导出 / 导入 JSON 备份文件 |

## 快速上手

1. 打开[在线地址](https://jacketlong23.github.io/Fund-OS/)，首次进入自带示例数据，直接增删改即可覆盖
2. 点右上角「＋ 记一笔」记录经费收支
3. 点顶部课题组名称可自定义名称（如「某某课题组经费」）
4. 定期用「导出」备份数据；换设备后用「导入」恢复

## 数据说明

- 数据保存在当前浏览器的 **localStorage** 中，刷新、关闭网页、重启电脑都不会丢失
- 以下情况会导致数据不可见：更换浏览器 / 设备、无痕模式、主动清除网站数据
- 不同设备打开同一网址各自记账，互不可见（纯本地应用，无服务器）
- 建议定期「导出 JSON」备份

## 技术栈

纯静态站点，零构建、零依赖：

```
index.html    # 页面结构
styles.css    # 极简设计（响应式，手机 / 桌面自适应）
app.js        # 原生 JS：记账逻辑 + localStorage 持久化
```

## 本地运行

无需任何环境，直接用浏览器打开 `index.html` 即可；或：

```bash
npx serve .        # 或 python -m http.server
```
